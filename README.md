# Упругое столкновение шаров

Моделируется столкновение двух гладких шаров по законам Гука и Герца. Результаты сравниваются с законами сохранения импульса и энергии.

[Отчёт](docs/report.md)
[Результаты экспериментов](docs/results.md)

Ильичев Василий — код; Ильина Алина — тесты, отчёт и описание.

## Запуск

Из папки проекта в Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python src/main.py
```

Параметры задаются в `main()` файла `src/main.py`: `mode = 1` — Гук, `mode = 2` — Герц. Программа выводит результаты расчёта, максимальную деформацию и время контакта и открывает график.

Ограничения на параметры (массы, радиусы и k больше нуля, шары не пересекаются в начальный момент, скорости до 0,1c, максимальная деформация не больше 0,1 меньшего радиуса) проверяются перед расчётом и обоснованы в [отчёте](docs/report.md#входные-параметры-и-ограничения).

## Тесты

```bash
python -m tests.tests
```

Проверяются полный импульс, кинетическая энергия, поперечный импульс каждого шара, максимальная деформация и время контакта.
