# Задачи на моделирование для курса «Цифровизация физических процессов» M2

Проект выполнили Ильичев Василий и Ильина Алина.

## Структура проекта

```text
physics_Ilichev_Ilina_M2/
├── docs/
├── src/
│   └── main.py
├── tests/
├── README.md
└── requirements.txt
```

`docs/` — документация, `src/` — исходный код, `tests/` — тесты.
Каталоги `docs/` и `tests/` пока пустые; Git не отслеживает пустые каталоги.

## Установка

```bash
python3 -m pip install -r requirements.txt
```

## Запуск

```bash
python3 src/main.py
```
