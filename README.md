Проект выполнили Ильичев Василий и Ильина Алина.

## Структура проекта

```text
physics_Ilichev_Ilina_M2/
├── docs/
├── src/
│   └── main.py
├── tests/
├── README.md
└── requirements.txt
```

`docs/` — документация, `src/` — исходный код, `tests/` — тесты.
Каталоги `docs/` и `tests/` пока пустые; Git не отслеживает пустые каталоги.

## Первый запуск (macOS / Linux)

Нужен установленный Python 3.8 или новее. Проверить версию:

```bash
python3 --version
```

1. Откройте терминал и перейдите в папку проекта:

```bash
cd /путь/к/physics_Ilichev_Ilina_M2
```

Замените `/путь/к/physics_Ilichev_Ilina_M2` на путь к своей папке. Во встроенном терминале редактора, открытом в корне проекта, этот шаг можно пропустить.

2. Создайте виртуальное окружение и активируйте его:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

3. Установите зависимости из `requirements.txt`:

```bash
python -m pip install -r requirements.txt
```

4. Запустите программу из корня проекта:

```bash
python src/main.py
```

Программа моделирует столкновение двух шаров и выводит в терминал время и координаты столкновения, а также скорости шаров после удара. Если столкновения нет, появится сообщение «Столкновение не произошло».

Начальные координаты, скорости, радиусы, массы, жёсткость `k` и режим взаимодействия задаются в функции `main()` в `src/main.py`. Режим `mode = 1` соответствует закону Гука, `mode = 2` — закону Герца. Аргументы командной строки не нужны. После расчёта открывается окно с графиком траекторий шаров. Закройте окно графика, чтобы завершить программу.

## Повторный запуск

В новом терминале перейдите в папку проекта, активируйте уже созданное окружение и запустите программу:

```bash
source .venv/bin/activate
python src/main.py
```

Повторно создавать окружение не нужно. Устанавливайте зависимости заново, если изменился `requirements.txt`.

Для выхода из виртуального окружения:

```bash
deactivate
```

Если появляется `ModuleNotFoundError`, активируйте окружение и выполните `python -m pip install -r requirements.txt`. Если Python не находит `src/main.py`, проверьте, что терминал открыт в корне проекта.

## Запуск в Windows (PowerShell)

Из папки проекта:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src\main.py
```

При повторном запуске достаточно последней команды.
