# Отчёт: упругое столкновение двух гладких шаров

Ильичев Василий - код; Ильина Алина - тесты, отчёт и описание.

## Задача и модель

Программа моделирует упругое столкновение двух гладких деформируемых шаров. Рассматриваются лобовые и косые удары, одинаковые и разные массы, неподвижные и движущиеся шары. Трение и вращение не учитываются, сила направлена вдоль линии центров.

Пусть R₁, R₂ - координаты центров, r₁, r₂ - радиусы. Деформация и уравнения движения:

```text
d = |R₁ − R₂|,  δ = max(r₁ + r₂ − d, 0),  n = (R₁ − R₂)/d

dR₁/dt = v₁,             dR₂/dt = v₂
m₁·dv₁/dt = F₁,          m₂·dv₂/dt = −F₁
Гук:   F₁ = kδn
Герц:  F₁ = kδ^(3/2)n
```

Во время контакта кинетическая энергия частично переходит в энергию деформации: U = kδ²/2 для Гука и U = 2kδ^(5/2)/5 для Герца. До и после удара U = 0.

## Визуализация

Программа выводит время и координаты первого контакта, скорости после удара. На графике сплошными линиями показаны траектории до столкновения, пунктиром - после; окружности обозначают положения шаров.

## Интегрирование

Первое касание находится из уравнения |d₀ + ut|² = (r₁ + r₂)², где u - относительная скорость:

```text
vᵢ,new = vᵢ + (Fᵢ/mᵢ)·Δt
Rᵢ,new = Rᵢ + vᵢ,new·Δt
μ = m₁m₂/(m₁ + m₂)
Δt = sqrt(μ/k)/10000
```

Шаг постоянный, расчёт заканчивается после разлёта при δ ≤ 0. длительность лобового контакта T = π√(μ/k)

## Аналитические проверки и tests

До и после упругого столкновения должны совпадать полный импульс и кинетическая энергия:

```text
P = m₁v₁ + m₂v₂
E = (m₁|v₁|² + m₂|v₂|²)/2
```

Из этих законов для лобового удара получаем скорости:

```text
v₁ = [(m₁ − m₂)u₁ + 2m₂u₂]/(m₁ + m₂)
v₂ = [2m₁u₁ + (m₂ − m₁)u₂]/(m₁ + m₂)
```

Для мгновенного косого удара сила не имеет поперечной составляющей, поэтому импульс каждого шара поперёк линии центров сохраняется:

```text
τ = (−nᵧ, nₓ)
pᵢ,⊥ = mᵢ(vᵢ·τ)
```

### Что проверяют тесты

Формулы находятся в `tests/analytics.py`, проверки - в `tests/tests.py`. В каждом опыте сравниваются импульс по x и y, кинетическая энергия и поперечный импульс каждого шара.

Проверяются 12 сценариев для обоих законов силы: лобовые и косые удары, разные массы, покой одного шара, встречное движение и движение вдогонку, смена знака поперечной скорости, поворот линии центров на 45° и 90°.

Допустимая разница: 10⁻⁸ кг·м/с для полного импульса, 10⁻⁷ относительной ошибки энергии, 10⁻³ кг·м/с для поперечного импульса.

**Все 120 проверок проходят.**

```bash
python -m tests.tests
```

## Численные эксперименты

При k = 10⁸ обе модели согласуются с формулами лобового удара:

| Массы m₁ и m₂, кг | Скорости до удара, м/с | Скорости после удара, м/с |
|---|---|---|
| 1; 1 | 2; 0 | 0; 2 |
| 2; 1 | 2; 0 | 0,666667; 2,666667 |
| 1; 1 | 2; −1 | −1; 2 |
| 2; 1 | 2; −1 | 0; 3 |

Для косого удара равных масс с u₁ = (2; 1), u₂ = (0; 0) м/с мгновенная модель даёт v₁ = (0; 1), v₂ = (2; 0). Максимальное отклонение компоненты скорости составляет 1,11·10⁻⁴ м/с для Гука и 6,70·10⁻⁴ м/с для Герца.

При росте k от 10⁶ до 10¹⁰ это отклонение уменьшается с 1,11·10⁻³ до 1,11·10⁻⁵ м/с для Гука и с 4,24·10⁻³ до 1,06·10⁻⁴ м/с для Герца. Более жёсткие шары приближаются к модели мгновенного удара.

Полные данные: [таблицы экспериментов](results.md)

## Вывод

Обе модели сохраняют импульс и энергию. При лобовом ударе равные массы обмениваются скоростями, разные - перераспределяют их согласно законам сохранения. При косом ударе результаты приближаются к мгновенной модели с ростом жёсткости.
